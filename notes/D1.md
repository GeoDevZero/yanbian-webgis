# Leaflet学习笔记
> 来源：HTML地图代码学习，Markdown复习文档

## 一、示例完整HTML‑Leaflet地图代码
```html
<!DOCTYPE html>
<html lang="zh">
<head>
  <meta charset="utf-8" />
  <title>我的第一张地图</title>
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
  <style>
    html, body { margin: 0; height: 100%; }
    #map { height: 100%; }
  </style>
</head>
<body>
  <div id="map"></div>

  <script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
  <script>
    // 1) 建地图，定位到延吉
    const map = L.map('map').setView([42.90, 129.51], 11);

    // 2) 加底图
    L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
      maxZoom: 19,
      attribution: '&copy; OpenStreetMap'
    }).addTo(map);

    // 3) 手写GeoJSON面要素
    const demo = {
      "type": "FeatureCollection",
      "features": [{
        "type": "Feature",
        "properties": { "name": "我的研究区" },
        "geometry": {
          "type": "Polygon",
          "coordinates": [[
            [129.40, 42.85], [129.62, 42.85],
            [129.62, 42.95], [129.40, 42.95],
            [129.40, 42.85]
          ]]
        }
      }]
    };

    // 4)渲染GeoJSON，绑定点击弹窗
    const layer = L.geoJSON(demo, {
      style: { color: 'red', weight: 2, fillOpacity: 0.15 },
      onEachFeature: (feature, lyr) => lyr.bindPopup(feature.properties.name)
    }).addTo(map);

    // 5)自动适配地图视野
    map.fitBounds(layer.getBounds());
  </script>
</body>
</html>
```

## 二、HTML关键标签属性解析
### 1. viewport移动端适配
```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```
- `width=device‑width`：网页宽度 = 设备屏幕宽度
- **`initial‑scale=1`**
  - 本义：initial初始；scale缩放
  - 含义：页面打开初始缩放倍数为1，100%原始大小，不放大不缩小
- 整体作用：解决手机端网页缩小、排版错乱、两侧留白，移动端网页标配。
  - `initial‑scale=0.5`：页面缩小一半
  - `initial‑scale=2`：页面放大一倍

### 2. link标签 rel属性
```html
<link rel="stylesheet" href="xxx.css" />
```
- **rel**：本义 relationship 关系、关联；描述引入外部文件与当前网页的关系
- `rel="stylesheet"`：代表引入的文件是CSS样式表
- 作用：引入Leaflet的css，让地图控件、弹窗、图标样式正常渲染
> 区分：`<link>`配合`rel`引入CSS；`<script src="...">`的`src`用来引入JS脚本。

## 三、Leaflet GIS核心API（单词本义 + 代码功能）
| API | 单词本义 | 代码功能说明 |
|-----|---------|------------|
| tileLayer | tile瓦片；layer图层 | **瓦片图层**；加载地图底图瓦片图片，为空白地图拼接背景地图；没有它地图只有画布没有地图图像 |
| geometry | 几何 | 存储地理要素**形状与经纬度坐标**；<br>配套properties存储文字属性信息<br>Point点 / LineString线 / Polygon面 |
| bindPopup | bind绑定；popup弹窗 | 给点/线/面要素绑定弹窗；点击图形弹出文字内容 |
| fitBounds | fit适配；bounds边界、范围 | 地图自动平移+缩放，让视口刚好完整显示指定地理范围；<br>配合`getBounds()`获取图层的最大最小经纬度边界 |

## 四、JSON / GeoJSON基础
1. **JSON**
    - 全称本义：`JavaScript Object Notation` JavaScript对象表示法
    - 作用：轻量文本数据存储格式，跨软件通用；JSON键名**必须双引号，不能写注释**。
2. **GeoJSON**
    - JSON的子集，专门存储GIS地理空间数据；
    - ⚠️易错点：
      1. GeoJSON坐标顺序：`[经度,纬度]`
      2. Leaflet setView/marker坐标顺序：`[纬度,经度]`
      3. Polygon多边形坐标必须闭环，起点和终点坐标完全一致。
    - 结构：
      - `FeatureCollection`：要素集合，可以存放多个点线面
      - `Feature`：单个地理要素
      - `properties`：属性信息（名称等文本）
      - `geometry`：几何坐标信息

## 六、高频易错考点汇总
1. 坐标顺序大坑：Leaflet地图对象`setView([纬度,经度])`；GeoJSON几何`coordinates([经度,纬度])`
2. Polygon多边形，坐标数组首尾坐标必须一样实现闭合
3. 引入资源顺序：先leaflet.css → 再leaflet.js → 最后写自己的JS地图代码
4. tileLayer是底图背景；geoJSON是叠加在底图之上的矢量图层
5. fitBounds可以替代手动写中心点和缩放等级，自动适配研究区范围
## 原理：为什么必须起服务器？（2026-10-01 理解）

### 一台电脑同时扮演两个角色
- **服务器**：`python -m http.server 8000` —— 守住 8000 端口，把当前文件夹当成"对外公开目录"，等别人来要文件。窗口不能关，Ctrl+C 停止。
- **客户端**：浏览器访问 `http://localhost:8000` —— 向本机 8000 端口要东西。

### 完整数据流
1. 浏览器要 `index.html` → 服务器给它
2. 读到 `<script src="leaflet.js">` → 向 unpkg CDN 要 leaflet.js
3. 执行 JS，读到 `fetch('./yanbian.geojson')` → **又向同一个服务器要** geojson
4. Leaflet 把坐标画成多边形

### 为什么不能双击 html？
- 双击时地址是 `file:///D:/...`，浏览器有**同源策略**：`file://` 不允许 fetch 读本地其他文件。
- 原因：否则任何下载来的恶意 html 双击后都能偷读你硬盘里的文件并外传，所以浏览器把 `file://` 权限锁死了。
- `http://localhost:8000` 被当成正常网站，fetch 读同源文件才合法。
- **一句话：`file://` 是本地文件，`http://` 是网站，浏览器只信任后者。**

### 为什么必须在"那个文件夹"里执行？
- `http.server` 把**当前目录**当作网站根目录。
- 在 `C:\Users\Lenovo` 执行 → 根目录是整个用户文件夹，找不到 index.html。
- 在 `D:\code\webgis-day` 执行 → 根目录是项目，正常。
- 这就是"当前目录（cwd）"的意义。

### 端口是什么
- 端口 = 门牌号。一台电脑可同时跑多个服务器，靠端口区分。
- `localhost` = 本机；`8000` = 端口。

### 这条知识以后用在哪
- D3/D4：浏览器 `fetch` 调我自己写的后端接口，流程完全一样。
- 部署到 Vercel：只是把"我电脑上的服务器"换成"云上的服务器"，架构不变。
- 面试常问："前端为什么不能双击打开？" 答案 = 同源策略 + `file://` 协议限制。
